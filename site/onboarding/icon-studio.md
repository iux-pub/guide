아이콘을 한국어로 찾아 세트에 넣고, 카탈로그에 없는 것만 말로 요청해 만드는 도구다. 각자 자기 맥에서 돌린다.

디자이너는 브라우저만 보면 되고, 터미널은 처음 준비할 때 한 번만 쓴다.

## 처음 한 번

```bash
git clone https://github.com/iux-pub/guide.git
cd guide
npm install
```

Claude에 로그인한다. 「만들기」에 필요하고 **각자 자기 구독**으로 돈다.

```bash
bash scripts/setup-claude-auth.sh
```

브라우저가 열리면 로그인하고, 발급된 토큰을 복사한 뒤 터미널로 돌아와 Enter를 누른다.
토큰은 `~/.config/icon-studio/auth.env`에 저장되고 다시 물어보지 않는다.

> 토큰은 비밀번호와 같다. **채팅·메신저·문서에 붙여 넣지 않는다.**
> 실수로 노출했으면 `claude auth logout` 후 다시 발급한다.

## 켤 때

```bash
npm run studio
```

화면과 일꾼이 함께 뜨고 브라우저가 열린다. 멈출 때는 `Ctrl+C`.

**찾기와 내보내기는 로그인 없이도 된다.** 카탈로그에서 세트에 넣는 것도 로그인이 필요 없다.
로그인은 「만들기」에서만 쓴다.

## 화면 셋

### 찾기

찾는 범위가 둘이다.

| 범위 | 뜻 |
|---|---|
| 세트 | 우리가 채택한 아이콘. 번호가 붙어 있어 **바로 쓴다** |
| 카탈로그 전체 | 구글 Material Symbols 전량(3,900여 종). 찾고 미리 볼 뿐 **아직 쓸 수 없다** — 「세트에 넣기」를 해야 쓴다 |

세트에서 찾다가 없으면 「카탈로그에서는 N종이 찾아집니다」가 뜬다. 눌러서 넘어간다.
카탈로그에서는 이미 세트에 있는 것에 **세트** 표시가 붙는다 — 누르면 코드가 나오고, 같은 아이콘을 두 번 넣지 않는다.

**한국어로 찾는다.** 카탈로그 전부에 한국어 이름과 검색어가 4~8개씩 붙어 있다. 영어 이름을 몰라도 되고,
영어 동의어(purchase·padlock·envelope)로도 걸린다.

| 친 말 | 나오는 것 |
|---|---|
| 장바구니 | shopping_cart · 장바구니 결제 · 장바구니 담기 |
| 영수증 | receipt · receipt_long |
| 조직도 | account_tree |
| 돋보기 | search |
| 햄버거 | menu |
| purchase | shopping_cart 외 |

띄어 쓴 말은 모두 걸려야 한다(「장바구니 결제」). 「아이콘」이라는 말은 아무것도 가르지 않으므로 무시된다.
**카탈로그에도 없는 것**(제주의 귤·한라산 같은 지역 상징)은 만들기로 넘어간다.

#### 카탈로그에서 세트에 넣기

카탈로그의 아이콘을 누르면 **네 표정(기본·슬림·볼드·필)이 미리 나온다.** 보이는 그대로 들어온다 —
미리보기와 채택이 같은 코드로 구글 원본을 받아 옮기기 때문이다.

1. **이름** — 영문 소문자와 붙임표. 구글 이름에서 자동으로 채워진다(`shopping_cart` → `shopping-cart`)
2. **찾을 말** — 한국어로 이미 채워져 있다. 고쳐도 된다
3. **분류** — 구글 분류에서 짐작해 골라 둔다. 틀렸으면 바꾼다
4. 「세트에 넣기」

이름이 규칙에 어긋나는 것이 약 150종 있다(숫자로 시작 · `new`·`big` 같은 금지 단어 · 네 마디 초과).
그때는 이유와 **제안한 이름**이 뜬다 — 제안은 출발점이니 뜻에 맞게 고쳐 쓴다.

**번호는 넣는 순간 영구히 붙는다.** 지워도 다시 쓰지 않으므로 되돌릴 수 없다. 이름은 신중히 짓는다.

넣은 직후 코드가 나온다. 단, 두 가지를 알아 둔다.

- 저장소에 올리기 전까지는 **이 서버에만 있다.** 아래 「만든 아이콘을 팀에 공유하려면」을 따른다
- 폰트와 스프라이트는 저장소에서 빌드(`npm run icons:build`)해야 들어간다. 그 전에 내보내기를 받으면
  **SVG 방식으로는 되지만 폰트(`span`) 방식은 빈 칸이 나온다** — 받은 묶음의 `README.txt`에 해당 이름이 적힌다

### 상세

미리보기 아래에 **표정 단추**가 있다 — 슬림·레귤러·볼드·필. 누르면 그림과 코드가 함께 바뀌고,
「SVG 파일 받기」도 고른 표정으로 내려받는다.

| 표정 | 쓰는 곳 |
|---|---|
| 슬림 | 32px 이상 큰 자리, 옅은 보조 정보 |
| 레귤러 | 기본. 본문 옆에서 글자와 무게가 맞는다 |
| 볼드 | 버튼·헤더처럼 눈이 먼저 닿아야 하는 자리 |
| 필 | 선택·활성 상태 (탭 현재 항목, 즐겨찾기 켬) |

**그 아이콘이 가진 표정만 단추로 나온다.** 필이 안 보이면 그 형태에는 채울 면이 없다는 뜻이다
(돋보기·화살표 등). 없는 표정을 코드에 직접 쓰면 화면에 빈 네모가 나온다.

한 화면에서 표정을 섞지 않는다 — 굵기가 뒤섞이면 중요도가 다른 것처럼 읽힌다.

### 만들기

**「만들기가 지금 멈춰 있습니다」가 뜨면** 요청을 넣어도 처리되지 않는다.
일꾼(생성을 맡는 프로세스)이 멈춘 것으로, 대개 로그인 자격이 만료된 경우다.
그때는 「4개 만들기」 단추도 눌리지 않는다 — 처리되지 않을 요청을 쌓지 않으려는 것이다.
**찾기와 내보내기는 그대로 된다.** UX팀에 알리면 된다.

**먼저 찾아본다.** 요청문을 적는 동안 카탈로그에 비슷한 아이콘이 있는지 아래에 보여 준다.
누르면 바로 세트에 넣을 수 있다. 만드는 데는 몇 분이 걸리고 결과는 구글 아이콘만 못한 경우가 많다 —
있으면 그것을 쓰는 편이 빠르고 낫다.

한 문장으로 적고 「4개 만들기」를 누른다. 보통 **1~2분** 걸린다. 좌표를 하나씩 놓는 일이라 원래 느리고,
창을 닫아도 된다. 서버가 한 번에 **하나씩** 그린다 — 여럿을 한꺼번에 돌리면 서로 CPU를 다투다
**넷 다** 시간 초과로 떨어지기 때문이다. 요청은 큐에 쌓이고 일꾼이 순서대로 처리하므로
**창을 닫고 다른 일을 해도 된다.**

**회사 로고나 발주처 CI처럼 정해진 모양은 만들지 않는다.** 원본 SVG를 그대로 쓴다.
참조 그림을 넣어 옮기게 하는 기능을 2026-10-05에 걷어냈다 — 참조를 붙인 요청 8건 가운데 5건이 실패하고
2건은 끝나지 않았으며, 후보를 낸 1건도 1개뿐이었다. 좌표를 모델이 손으로 옮기는 방식으로는 원본과 같은 것을 기대하기 어렵다.

후보마다 판정이 붙는다.

| 표시 | 뜻 |
|---|---|
| 초록 | 씨앗과 굵기·여백이 맞는다 |
| 주황 | 쓸 수는 있지만 조금 튄다. 눈으로 확인한다 |
| 빨강 | 규격 위반이라 고를 수 없다 |

**작은 크기만 보고 판단하지 않는다.** 16px에서는 테두리와 내부 요소가 뭉쳐 「꽉 찬 덩어리」처럼
보이는데 48px로 보면 멀쩡한 경우가 많다. 두 크기가 다 통과해야 쓸 만한 아이콘이다.

이름을 정하고 「이걸로 정하기」를 누르면 세트에 들어간다. **자동으로 들어가는 것은 없다.**

### 표정 만들기 — 우리가 만든 아이콘도 네 얼굴을 갖게

씨앗은 슬림·레귤러·볼드·필 넷을 갖는데, 우리가 만든 아이콘은 승인 직후에는 **기본 하나뿐**이다.
볼드로 통일한 화면에 그 아이콘만 혼자 얇게 뜬다.

우리가 만든 아이콘을 열면 표정 단추 옆에 **「+ 슬림·볼드·필 만들기」**가 붙는다
(씨앗에는 안 붙는다 — 구글에서 받아 오므로 만들 일이 없다). 누르면 만들기 탭으로 옮겨 가고,
없는 표정만 골라 만든다. **표정 하나에 10분 안팎** 걸리고 둘씩 나눠 돌린다 — 좌표를 그대로 두고 굵기만 바꾸는
일이라 새로 그리기보다 오래 걸린다. 창을 닫고 다른 일을 해도 된다.

결과는 **기본을 맨 왼쪽에 두고 나란히** 나온다. 같은 아이콘인지 눈으로 볼 수 있어야 하기 때문이다.
숫자도 함께 적는다.

| 숫자 | 뜻 |
|---|---|
| 획 | 선 두께. 슬림 0.85~1.16 · 볼드 1.67~2.14가 씨앗 범위다 |
| 기본의 N배 | 면적. 슬림은 0.65배쯤, 볼드는 1.4배쯤이 정상이다 |
| 자리 어긋남 | 기본과 테두리가 얼마나 어긋났나. **같은 아이콘인지 보는 자다** |

통과한 것만 미리 체크돼 있고, 막힌 것도 지우지 않고 보여 준다 — 기계가 「이상하다」고는 해도
「그러니 빼라」고 정할 수는 없다. 체크한 것만 「고른 표정 넣기」로 들어간다.

**채울 면이 없는 형태는 필을 만들지 않는다.** 돋보기·화살표처럼 선으로만 된 것이 그렇다.
그때는 「채울 면이 없는 형태입니다」라고 적힌다.

### 내보내기

프로젝트가 쓰는 아이콘만 골라 **zip 하나**로 받는다. 풀어서 프로젝트의 `assets/icons/`에
그대로 넣으면 끝이다 — 폴더 구조가 이미 맞춰져 있다.

들어 있는 것 — 스프라이트, **폰트(woff2)**, CSS, 낱개 SVG, 라이선스 고지, 쓰는 법.
CSS는 Tailwind 없이 그대로 도는 순수 CSS다. 외부에서 불러오는 것이 하나도 없어 폐쇄망에서도 뜬다.

**함께 담을 표정을 고른다.** 기본(레귤러)은 늘 들어가고, 슬림·볼드·필은 고른 것만 따라온다.
고르는 순간 받게 될 파일 목록과 개수가 화면에 나온다 — 필이 40개로 뜨는 것은 정상이다.
채울 면이 없는 아이콘에는 필이 없다.

**프로젝트마다 쓰는 것만 담긴다.** 스프라이트·CSS·낱개 SVG에는 고른 아이콘만 들어가고, 세트가 수백 종이 되어도
프로젝트는 자기가 쓰는 만큼만 받는다. 폰트는 세트 전체를 싣는다 — 아이콘 하나에 0.1KB 안팎이라 부담이 없다.

세트에 넣었지만 저장소에서 아직 빌드하지 않은 아이콘이 섞여 있으면 받은 뒤 화면에
「폰트에 아직 없어 SVG 방식으로만 쓸 수 있습니다」가 뜨고, `README.txt` 맨 위에 그 이름이 적힌다.

## 만든 아이콘을 팀에 공유하려면

**만들거나 카탈로그에서 넣은 것은 그 서버에만 있습니다.** 저장소에 넣기 전까지는 다음 배포 때 사라집니다 —
스튜디오가 쓰는 폴더가 저장소 사본이고, 배포가 그 사본을 원본으로 되돌리기 때문입니다.
만들고 나면 찾기 화면 맨 위에 그 사실이 뜹니다.

### NAS 스튜디오에서 만들었다면

찾기 화면 위쪽에 **「저장소에 올리기」**가 보이면 그것만 누르면 끝입니다.
SVG·표정 파일과 대장 번호·검색어가 함께 올라가 팀 전체가 씁니다.

「패치 내려받기」가 보인다면 그 서버에 아직 저장소 쓰기 권한이 없다는 뜻입니다.
그때는 아래처럼 옮깁니다 (UX팀에 권한 설정을 요청해도 됩니다).

1. 찾기 화면의 **「패치 내려받기」**를 누릅니다. 또는

   ```bash
   curl -sO https://footer.kr/guide/_icons/api/pending.patch
   ```

2. 자기 clone에 옮깁니다. **SVG·표정 파일뿐 아니라 대장 번호와 검색어까지 함께 갑니다** —
   낱개 SVG만 받으면 번호가 빠져 반쪽입니다.

   ```bash
   git apply pending.patch
   npm run icons:build     # 스프라이트·폰트·CSS 다시 만들기
   npm run check           # 규격 검사
   ```

3. 커밋해서 올립니다.

   ```bash
   git add -A && git commit && git push
   ```

### 내 컴퓨터에서 돌렸다면

바로 2번부터 하면 됩니다.

```bash
npm run icons:build
npm run check
git add -A && git commit && git push
```

`contracts/icon-codepoints.json`의 **번호는 한 번 주면 영구히 고정한다.** 밀리면 이미 납품한
사이트의 아이콘이 전부 다른 그림으로 바뀐다.

## 상시로 켜 두려면

터미널을 켜 둘 필요가 없어진다.

```bash
bash studio/install-service.sh
```

## NAS에 올린 것을 갱신하려면

`npm run deploy:nas` 한 줄이면 문서 사이트와 스튜디오가 함께 바뀐다.
검사·빌드부터 무중단 교체, 주소 200 확인, 스튜디오 재기동까지 들어 있다.
**비밀번호를 물어보지 않는다** — 스튜디오 프로세스는 계정 권한으로 돌고,
`start.sh`가 `nohup setsid`로 세션에서 떼어 내 ssh가 끊겨도 살아남는다.

root가 필요한 자리는 딱 둘이고 **처음 설치할 때 한 번뿐**이다 —
부팅 자동 시작(rc.d 등록)과 nginx 경로 설정.
