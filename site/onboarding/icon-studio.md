없는 아이콘을 말로 요청해 만들고, 눈으로 골라 세트에 넣는 도구다. 각자 자기 맥에서 돌린다.

디자이너는 브라우저만 보면 되고, 터미널은 처음 준비할 때 한 번만 쓴다.

## 처음 한 번

```bash
git clone https://github.com/iux-pub/guide.git
cd guide
npm install
```

Claude에 로그인한다. 「만들기」에 필요하고 **각자 자기 구독**으로 돈다.

```bash
bash scripts/setup-claude-auth.sh
```

브라우저가 열리면 로그인하고, 발급된 토큰을 복사한 뒤 터미널로 돌아와 Enter를 누른다.
토큰은 `~/.config/icon-studio/auth.env`에 저장되고 다시 물어보지 않는다.

> 토큰은 비밀번호와 같다. **채팅·메신저·문서에 붙여 넣지 않는다.**
> 실수로 노출했으면 `claude auth logout` 후 다시 발급한다.

## 켤 때

```bash
npm run studio
```

화면과 일꾼이 함께 뜨고 브라우저가 열린다. 멈출 때는 `Ctrl+C`.

**찾기와 내보내기는 로그인 없이도 된다.** 로그인은 「만들기」에서만 쓴다.

## 화면 셋

### 찾기

검색과 분류로 추린다. 아이콘을 누르면 48·24·20·16px 미리보기와 붙여 넣을 코드가 나온다.
초록 점이 붙은 것은 우리가 만든 아이콘, 나머지는 구글에서 가져온 것이다.

**한국어로 찾는다.** 이름은 영어지만 「달력」·「즐겨찾기」·「찾아오는길」·「휴지통」처럼
평소 쓰는 말로 치면 걸린다. 영어 이름을 몰라도 된다.

| 친 말 | 나오는 것 |
|---|---|
| 달력 | calendar |
| 즐겨찾기 | bookmark · star |
| 찾아오는길 | map-pin |
| 전체메뉴 | menu |
| 통계 | chart-bar · table |

찾는 말이 안 걸리면 그 말을 사전에 넣을 값어치가 있다는 뜻이다 — UX팀에 알린다.

미리보기 아래에 **표정 단추**가 있다 — 슬림·레귤러·볼드·필. 누르면 그림과 코드가 함께 바뀌고,
「SVG 파일 받기」도 고른 표정으로 내려받는다.

| 표정 | 쓰는 곳 |
|---|---|
| 슬림 | 32px 이상 큰 자리, 옅은 보조 정보 |
| 레귤러 | 기본. 본문 옆에서 글자와 무게가 맞는다 |
| 볼드 | 버튼·헤더처럼 눈이 먼저 닿아야 하는 자리 |
| 필 | 선택·활성 상태 (탭 현재 항목, 즐겨찾기 켬) |

**그 아이콘이 가진 표정만 단추로 나온다.** 필이 안 보이면 그 형태에는 채울 면이 없다는 뜻이다
(돋보기·화살표 등). 없는 표정을 코드에 직접 쓰면 화면에 빈 네모가 나온다.

한 화면에서 표정을 섞지 않는다 — 굵기가 뒤섞이면 중요도가 다른 것처럼 읽힌다.

### 만들기

한 문장으로 적고 「4개 만들기」를 누른다. 요청은 큐에 쌓이고 일꾼이 순서대로 처리하므로
**창을 닫고 다른 일을 해도 된다.** 보통 1~2분 걸린다.

후보마다 판정이 붙는다.

| 표시 | 뜻 |
|---|---|
| 초록 | 씨앗과 굵기·여백이 맞는다 |
| 주황 | 쓸 수는 있지만 조금 튄다. 눈으로 확인한다 |
| 빨강 | 규격 위반이라 고를 수 없다 |

**작은 크기만 보고 판단하지 않는다.** 16px에서는 테두리와 내부 요소가 뭉쳐 「꽉 찬 덩어리」처럼
보이는데 48px로 보면 멀쩡한 경우가 많다. 두 크기가 다 통과해야 쓸 만한 아이콘이다.

이름을 정하고 「이걸로 정하기」를 누르면 세트에 들어간다. **자동으로 들어가는 것은 없다.**

### 내보내기

프로젝트가 쓰는 아이콘만 골라 **zip 하나**로 받는다. 풀어서 프로젝트의 `assets/icons/`에
그대로 넣으면 끝이다 — 폴더 구조가 이미 맞춰져 있다.

들어 있는 것 — 스프라이트, **폰트(woff2)**, CSS, 낱개 SVG, 라이선스 고지, 쓰는 법.
CSS는 Tailwind 없이 그대로 도는 순수 CSS다. 외부에서 불러오는 것이 하나도 없어 폐쇄망에서도 뜬다.

**함께 담을 표정을 고른다.** 기본(레귤러)은 늘 들어가고, 슬림·볼드·필은 고른 것만 따라온다.
고르는 순간 받게 될 파일 목록과 개수가 화면에 나온다 — 필이 40개로 뜨는 것은 정상이다.
채울 면이 없는 아이콘에는 필이 없다.

## 만든 아이콘을 팀에 공유하려면

승인하면 자기 clone에만 들어간다. 팀 전체가 쓰려면 커밋해서 올린다.

```bash
npm run icons:build     # 스프라이트·폰트·CSS 다시 만들기
npm run check           # 규격 검사
git add -A && git commit && git push
```

`contracts/icon-codepoints.json`의 **번호는 한 번 주면 영구히 고정한다.** 밀리면 이미 납품한
사이트의 아이콘이 전부 다른 그림으로 바뀐다.

## 상시로 켜 두려면

터미널을 켜 둘 필요가 없어진다.

```bash
bash studio/install-service.sh
```
