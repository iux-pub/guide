# 뷰티 스코어카드

> AI가 디자인 결과물을 자기 검증하는 미적 기준.
> design-audit.md가 "틀린 것 잡기"라면, 이건 "이쁜 것 만들기".
> 디자인 생성 후 이 기준으로 자기 평가하라. 70점 미만이면 다시 만들어라.

## 채점 (100점 만점)

| 영역 | 배점 | 기준 |
|------|------|------|
| 타이포그래피 | 25 | 대비, 리듬, 위계 |
| 여백과 호흡 | 20 | 밀도, 섹션 간격, 비율 |
| 색상과 분위기 | 20 | 절제, 조화, 깊이감 |
| 레이아웃 구성 | 15 | 시선 흐름, 비대칭, 리듬 |
| 모션과 인터랙션 | 10 | 자연스러움, 목적성 |
| 디테일 폴리시 | 10 | 마감, 일관성, 그레인 |

---

## 1. 타이포그래피 (25점)

### 크기 대비
- 히어로/디스플레이 텍스트는 본문의 **3배 이상** — `clamp(4.8rem, 8vw, 12rem)`
- 데스크톱 히어로: **72~160px**. 48px 이하는 감점
- 모바일 히어로: **36~64px**
- 본문: 16px (1.6rem) 기준

### Weight 대비
- 같은 서체 내 극단적 대비 사용: Thin(100~300) + Bold(700~900)
- 비슷한 weight 조합(400 vs 500)은 위계가 불명확 — 감점

### 서체 규칙
- 서체 **최대 2종**. 3종 이상은 산만함
- 한국어: Pretendard GOV + 세리프(마루부리/Noto Serif KR) 페어링 가능
- 본문 줄 길이: **45~75자** (한국어 22~38자)
- 행간: 본문 1.6~1.8, 히어로 1.0~1.2

### 감점 기준
- 히어로가 본문의 2배 이하: **-8**
- Weight 대비 200 미만: **-5**
- 서체 3종 이상: **-5**
- 줄 길이 80자 초과: **-3**

---

## 2. 여백과 호흡 (20점)

### 뷰포트 여백 비율
- 첫 뷰포트의 **40% 이상**은 비어있어야 한다
- 콘텐츠가 뷰포트 60% 이상 채우면 답답함 — 감점

### 섹션 간격
- 데스크톱: 섹션 간 **120~200px** (프리미엄은 240px)
- 모바일: 섹션 간 **60~80px**
- KRDS `4rem`(24px)/`2.4rem`(24px)은 컴포넌트 내부용. 섹션 간격은 별도 스케일(`120~200px` 데스크톱) 적용

### 비례 리듬
- 섹션 내부 패딩과 섹션 간 간격의 비율이 **1:2 이상**
- 요소 간격이 모두 동일하면 리듬 없음 — 감점

### 감점 기준
- 뷰포트 여백 30% 미만: **-8**
- 섹션 간격 80px 미만 (데스크톱): **-5**
- 모든 간격이 균일: **-4**

---

## 3. 색상과 분위기 (20점)

### 절제
- 강조색(accent)은 화면의 **10~15%** — 넘치면 산만, 부족하면 밋밋
- 중립색(neutral)이 전체의 **70% 이상** 차지

### 배경
- 모든 색은 `var(--color-*)` 토큰으로 칠한다. 오프화이트·소프트 블랙을 raw hex로 만들지 않는다(R-01)
- 구획은 표면 단계로 나눈다: `--color-bg`(기본) → `--color-bg-subtler`·`--color-bg-subtle`(구획 띠) → `--color-surface`(카드·패널)
- 배경 톤을 바꿔야 하면 `tokens/brand.json`에서 정하고 `npm run check:contrast`를 통과시킨다
- 다크·고대비 모드는 토큰 모드 전환으로 처리한다. 화면마다 색을 따로 고르지 않는다

### 깊이감
- 깊이는 표면 단계 차이 + 1px 보더(`--color-border-light`) + KRDS 3단계 그림자로 만든다
- 장식 그라데이션·그라데이션 글자·글래스·컬러 글로우는 깊이 수단이 아니다(R-34). 허용되는 그라데이션은 사진 위 스크림(투명 → 검정 알파)과 단색 페이드뿐이다
- 그림자: 하나의 광원 방향으로 일관되게. 여러 방향 금지

### 감점 기준
- 강조색 20% 초과: **-6**
- 구획이 표면 단계 없이 한 배경색으로만 이어짐: **-5**
- 그림자 방향 불일치: **-4**
- 색상 4종 이상 accent: **-5**
- 장식 그라데이션·글래스·컬러 글로우 사용: **-5** (R-34 — 보라·남색 계열은 표현 등급과 무관하게 오류)

---

## 4. 레이아웃 구성 (15점)

### 시선 초점
- 한 뷰포트 안에 focal point는 **딱 1개**
- 모든 것이 동등한 크기/강조면 아무것도 안 보임

### 리듬과 변화
- 전폭(full-bleed) ↔ 컨테이너(max-width) 섹션을 **교차 배치**
- 모든 섹션이 같은 구조(이미지 좌 + 텍스트 우 반복)면 지루함 — 감점

### 비대칭
- 의도적 오프셋: `margin-left: 8vw` 같은 비대칭 배치로 시선 유도
- 좌우 완전 대칭만 사용하면 단조로움

### 감점 기준
- 뷰포트당 focal point 2개 이상: **-5**
- 3개 이상 섹션이 동일 구조 반복: **-5**
- 전체가 좌우 대칭만: **-3**

---

## 5. 모션과 인터랙션 (10점)

### 진입 애니메이션
- 이동 거리: **20~40px** + fade. 100px 이상은 과도
- Duration: **0.3~0.6s**. 1s 이상은 답답
- Easing: `cubic-bezier(0.16, 1, 0.3, 1)` (easeOutExpo 계열). linear/ease는 구식
- Stagger: 연속 요소 간 **0.05~0.1s** 딜레이

### Hover
- 이미지: `scale(1.03~1.05)`. 1.1 이상은 과함
- 텍스트 링크: 밑줄 애니메이션 또는 색상 전환
- 버튼: 배경색 전환 + 미묘한 `translateY(-1~-2px)`

### 필수
- `prefers-reduced-motion` 대응 필수
- 장식 목적만의 애니메이션 금지 — 모든 모션에 목적이 있어야

### 감점 기준
- 이동 거리 100px 이상: **-3**
- Duration 1s 초과: **-3**
- linear easing 사용: **-2**
- reduced-motion 미대응: **-2**

---

## 6. 디테일 폴리시 (10점)

### 표면과 깊이
- 표면은 단색 토큰(`--color-surface`, `--color-bg-subtler`)으로 칠하고, 층은 1px 보더(`--color-border-light`)와 KRDS 3단계 그림자로 구분한다
- 그림자는 KRDS 검정 알파(shadow1·2·3 = 5·8·12%) 조합만 쓴다 — 경고·캘린더 `0 0 0.2rem` + `0 0.4rem 0.8rem`(shadow1·2), 카드·메뉴·패널 `0 0 0.2rem` + `0 0.8rem 1.6rem`(shadow2·3), 모달 `0 0 0.2rem` + `0 1.6rem 2.4rem`(shadow2·3). 값은 `alert`·`card`·`modal` 컴포넌트 CSS의 것을 그대로 쓴다. 색 있는 글로우 그림자는 쓰지 않는다(R-34)
- 사진·영상 위 글자는 스크림(단색 알파 40~60% 또는 투명 → 검정 알파 그라데이션) 위에만 얹고, 대비 4.5:1은 스크림 위에서 잰다. 글래스(`backdrop-filter`)로 대신하지 않는다(R-34)

### 일관성
- border-radius: KRDS 단계(2·4·6·8·10·12px, 원형 제외 최대 12px)를 따른다. 컨테이너 높이 × 1/8이 출발점이다
- 같은 크기의 컴포넌트끼리 반경이 다르면 감점

### 마감
- 자동 생성 이름(`Frame 427`) 잔존 금지
- placeholder 이미지/텍스트(`Lorem ipsum`) 잔존 금지
- 아이콘은 카탈로그에서 가져오고(R-27) 스타일을 통일한다 (outline/filled 혼용 금지)
- 이모지를 아이콘·불릿·배지·제목 장식으로 쓰지 않는다(R-36). ©·※·★ 같은 글자 기호는 괜찮다

### 감점 기준
- border-radius 스케일 불일치: **-3**
- 아이콘 스타일 혼용 또는 이모지 아이콘·장식: **-3**
- placeholder 잔존: **-4**

## 한국 시장 보정

한국 웹 특성상 글로벌 기준을 그대로 적용하면 안 되는 부분:

| 항목 | 글로벌 | 한국 보정 |
|------|--------|----------|
| 히어로 텍스트 | 72~160px | **48~96px** (한글은 글자 크기가 커서 상대적으로 작아도 임팩트) |
| 섹션 간격 | 120~200px | **80~160px** (정보 밀도 높은 문화) |
| 행간 | 1.5 | **1.6~1.8** (한글 특성, 최소 `line-height: 1.6`) |
| 카드 gap | 24~32px | **16~24px** (커머스/포털 밀도) |
| 모바일 우선 | 권장 | **필수** (트래픽 70%+) |

## 빠른 자기 검증 (5문항)

1. 히어로 텍스트가 본문의 3배 이상 크고, weight 대비가 명확한가?
2. 첫 뷰포트의 40% 이상이 비어있고, 시선 초점이 1개인가?
3. 강조색이 화면의 15% 미만이고, 깊이를 장식 효과(그라데이션·글래스·글로우) 없이 표면 단계와 KRDS 그림자로 만들었는가?
4. 3개 이상 섹션이 동일 구조를 반복하지 않는가?
5. 모든 모션이 0.6s 이내이고, easeOut 계열 easing을 사용하는가?
